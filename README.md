# GameMod

Describe a change to a single-player game you own, and GameMod builds it as a mod into a private copy of the game. The game you installed isn't changed.

This repo holds only the installers. Get the newest one for your system:

- [macOS (Apple Silicon)](https://github.com/gamemod-ai/gamemod-releases/releases/latest/download/GameMod-macOS.dmg)
- [Windows](https://github.com/gamemod-ai/gamemod-releases/releases/latest/download/GameMod-Windows-setup.exe)
- [Linux (AppImage)](https://github.com/gamemod-ai/gamemod-releases/releases/latest/download/GameMod-Linux.AppImage)

Every version is under [Releases](https://github.com/gamemod-ai/gamemod-releases/releases).

You sign in with your GameMod access code. Get one at [gamemod.ai](https://gamemod.ai).

Questions or problems: info@gamemod.ai.
